# Liwi-Ka customer website — UI/interaction fixes (14 November 2026)

## Best Sellers
- Mobile cards now show only the image and product-name overlay. The product-info panel, price, description and add-to-cart control are hidden at the mobile breakpoint.
- Desktop cards use a fixed 320 × 360 px image viewport; uploaded image dimensions cannot change the frame size. Images fill the frame with `object-fit: cover`.
- Desktop product cards use a wrapping flex layout with `justify-content: center`, so every row is centered for one, two, three or more products.

## Shop and product dialog
- Removed the duplicate Shop category-filter handler; `shop.js` owns filtering and queries the live Firebase-rendered card list at click time.
- Removed the duplicate Shop price-sort handler; `shop-seasonals.js` owns sorting and reads the current rendered cards when the sort changes.
- Kept delegated card-click handling for dynamically rendered products and added keyboard activation for Enter/Space.
- The Shop dialog is hoisted to a direct child of `body`, outside the isolated/animated Shop `<main>` element.
- Replaced fixed-position body scroll locking (negative `top` offset) with an overflow lock that preserves the scroll coordinates. This avoids shifting the fixed dialog on mobile browsers.
- Corrected the mobile shell stacking rule: the parent bottom dock and free-delivery HUD now hide while the iframe product dialog is open, rather than being forced above it.
- The dialog remains a fixed viewport overlay with a translucent blurred backdrop; mobile dialog content uses the full iframe viewport.

## Free-delivery HUD
- The visible HUD responds to click, Enter and Space, and navigates to the Shop page. In the mobile shell it uses the shell's internal navigation function rather than leaving the iframe/app shell.

## Static verification performed
- JavaScript syntax checks: all shipped `.js` files passed `node --check`.
- CSS parsing: all 20 stylesheets parsed without syntax errors.
- HTML inventory: 24 HTML pages checked; no missing local `href`/`src` references and no duplicate element IDs.
- Targeted assertions passed for the mobile Best Sellers image/name-only rules, desktop fixed frame and row centering, single Shop filter and sort controllers, dynamic Shop-card modal opening, modal scroll restoration, modal backdrop, mobile dock hiding, and free-delivery Shop navigation.

## Verification limitation
A live interactive device/browser session was not available for this build, so the package has been validated through source, syntax, asset-reference and targeted behavior checks rather than a full visual cross-device acceptance test. Preview the ZIP before replacing the live GitHub Pages files.
